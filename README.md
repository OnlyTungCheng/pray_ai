# Đền Cầu Nguyện Dev

Interactive Next.js temple room for teams to prepare a project, perform a shared
ritual, and receive an oracle result before deploy, build, or migration.

## Development

```bash
npm install
npm run dev
npm run build
```

The application uses the Next.js App Router, Supabase for room state and realtime,
and Tailwind CSS for styling.

## Assets

Only production assets are kept under `public/`. The runtime inventory and asset
contract are documented in `docs/generated-image-assets.md`.
